# Sleep Quality Prediction using Machine Learning

## 📌 Project Overview
This project focuses on predicting students' sleep quality using Machine Learning techniques based on lifestyle and academic factors.

## 🎯 Objective
To analyze student sleep patterns and predict sleep quality using relevant features such as age, sleep duration, study hours, screen time, caffeine intake, and physical activity.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 📂 Dataset
The notebook uses `student_sleep_patterns.csv`.

The dataset contains 500 student records and 14 columns, including:
- Age
- Gender
- University Year
- Sleep Duration
- Study Hours
- Screen Time
- Caffeine Intake
- Physical Activity
- Sleep Quality

**Note:** The dataset is not included in this repository yet.

## ⚙️ Machine Learning Workflow
1. Data Loading and Exploration
2. Data Preprocessing
3. Feature Scaling using StandardScaler
4. Train-Test Split
5. Linear Regression Model Training
6. Model Evaluation

## 📊 Evaluation Metrics
- Mean Squared Error (MSE)
- R-squared (R²)
- Mean Absolute Error (MAE)

2. Install the required libraries:
   `pip install pandas numpy matplotlib scikit-learn`
3. Add the `student_sleep_patterns.csv` dataset to the project folder.
4. Open `model.ipynb` using Jupyter Notebook or VS Code.
5. Run all cells.
